Multi-Layer Authentication

Security Beyond Password.

SecureGraphical is a colour-based textual graphical password authentication system designed to improve resistance against shoulder surfing while maintaining a simple and efficient user experience.

Core Features

Designed for stronger authentication

SecureGraphical combines multiple authentication mechanisms into one streamlined system.

🔐

Text Password

User credentials are protected using secure password hashing instead of storing passwords in plain text.

🎨

Colour Authentication

Eight colour sectors are used as pass-colour and decoy-colour authentication elements.

🔄

Randomised Interface

Characters and colour positions are randomised to make direct observation more difficult.

🛡️

Shoulder Surfing Resistance

The graphical authentication mechanism reduces the usefulness of simply observing user input.

🧩

Multi-Layer Protection

Login requires multiple authentication stages instead of relying on a single password.

⚡

Simple User Experience

The system combines stronger security with an intuitive graphical interface.

Authentication Process

How SecureGraphical works

Four stages protect the user's account.

01

Register

Create an account using an email, text password and pass-colour.

02

Verify

Complete CAPTCHA and conventional password verification.

03

Authenticate

Use the colour-based graphical password mechanism.

04

Access

Successful authentication provides access to the dashboard.

Security Design

Built around layered protection

Security is applied at multiple stages of the authentication process.

Protection Mechanisms

✓
Password Hashing Text passwords are stored as cryptographic hashes.
✓
CAPTCHA Verification Helps distinguish legitimate users from automated requests.
✓
Randomised Characters The 16-character alphabet is randomly distributed.

Shoulder Surfing Defence

✓
Eight Colour Sectors One pass-colour is selected while the remaining colours act as decoys.
✓
Rotation Mechanism Characters can be rotated clockwise or anti-clockwise.
✓
Multi-Factor Authentication Multiple authentication layers increase the difficulty of unauthorised access.
