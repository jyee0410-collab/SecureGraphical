Why this authentication layer?

SecureGraphical combines a conventional password with a dynamic graphical authentication mechanism to provide an additional defence against visual observation attacks.

🎨
8 Colour Sectors Eight visually distinct sectors provide the colour-based structure required by the proposed scheme.
🔤
16-Character Alphabet The authentication alphabet contains eight lowercase letters (a–h) and eight numbers (1–8).
🎲
Dynamic Distribution Characters are initially distributed around the authentication wheel, making a fixed visual pattern less useful to an observer.
🔄
Rotational Interaction Users can rotate the character arrangement clockwise or anti-clockwise before making their selections.
🔢
Ordered Selection The authentication sequence is recorded in the exact order in which characters are selected.
🧩
Multi-Layer Authentication Users must successfully pass the text password and graphical authentication stages.
Authentication architecture MULTI-LAYER
Security principle: The graphical layer introduces a changing visual authentication state. This is intended to make direct observation less useful than observing a conventional static password entry.
